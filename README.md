# SizeToKB — Photo & Signature Resize to Exact KB

Free online tools for Indian exam form uploads: SSC, UPSC, NEET, JEE, Railway, IBPS and 190+ profiles.

**Domains:** [sizetokb.in](https://sizetokb.in) · sizetokb.com

## Features

- Exam photo & signature resizer (pre-set KB + dimensions)
- Custom / image resizer (exact min–max KB)
- Image → PDF and PDF compressor
- Privacy-first: processing in the browser
- Legal pages, HTML + XML sitemap, SEO metadata

## Develop

```bash
npm install
npm run dev
```

## Production build (static export for Hostinger)

```bash
npm run build
```

Upload the contents of the `out/` folder to Hostinger `public_html`.

See [DEPLOY.md](./DEPLOY.md) for the full Hostinger guide.
